## 👩‍💻 About Me

I'm a **Software Developer and BSc Computing graduate** with an unconventional route into tech — one that actually started more than **27 years ago**.

My first programming language was **Pascal**, which I learned while studying computer science in college.

Back then, access to computers was very different. I would write algorithms and code **on paper**, then wait for one of our twice-weekly, one-hour computer lab sessions to find out whether my code actually worked.

Three years later, I bought my first computer using money I'd saved from my college bursary.

I've barely spent a day away from technology since.

My journey took me through **photography, jewellery making, e-commerce, digital marketing, accounting and entrepreneurship**, but I never lost my fascination with:

```text
Algorithms → Information Systems → Technology → Problem Solving
```

Eventually, all those paths led me back to where I started.

**Software development.**

## 🛒 Modular E-Commerce Platform

> **PHP 8+ · MySQL · MVC · Stripe · Royal Mail API · PHPUnit · SSR**

My BSc Computing final project explores whether a **lightweight, modular e-commerce architecture** can provide SMEs with an alternative to plugin-heavy platforms.

Rather than relying on an existing e-commerce framework, I designed and built the platform **from the ground up**.

### 🏗️ Architecture

```text
Request
   ↓
Router
   ↓
Controller
   ↓
Service
   ↓
Repository
   ↓
Database
```

External services are isolated using adapters:

```text
StripeAdapter
RoyalMailAdapter
SocialMediaAdapter
```

### ✨ Features

* 🛍️ Product catalogue
* 🛒 Shopping cart
* 💳 Stripe Checkout integration
* 🔔 Stripe webhook order processing
* 📦 Order management
* 🚚 Royal Mail Click & Drop integration
* 👤 Customer authentication
* ⚙️ Admin dashboard
* ✏️ Product CRUD
* 🗄️ Repository-based database layer
* 🛡️ CSRF protection
* 🔐 Secure password hashing
* 🧪 Unit, integration and system testing
* ⚡ Performance and resource-efficiency evaluation

### 🎯 Project Focus

## 🤖 AI-Assisted Car Parts Management System

> **PHP · MySQL · Multimodal LLM API · Image Analysis · Structured Data**

One of my recent projects combines **traditional full-stack development with multimodal AI**.

I built a car-parts management application where a user can upload a photograph of an automotive component or product label.

Instead of manually entering all the product information, the application sends the image to a **multimodal LLM API**.

The model analyses the image, extracts information such as:

```text
Image
   ↓
LLM Vision Analysis
   ↓
Part / OEM Number Detection
   ↓
Product Information Extraction
   ↓
Structured Data
   ↓
Automatic Form Population
   ↓
Human Review
```

The extracted information is then used to **automatically populate the Add Product form**, ready for review before being saved.

### 🧠 What I explored

* Multimodal LLM APIs
* Image → structured-data extraction
* Prompt engineering
* Structured outputs
* API integration
* AI-assisted workflow automation
* PHP/MySQL application development
* Human-in-the-loop validation
